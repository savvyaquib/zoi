# Zoi

Single-page, scroll-driven marketing site for **Zoi**, a modern dining restaurant in
Ranchi. Image-heavy, minimal text, cinematic — the scroll *is* the experience.

Live venue details, the four-colour palette, and the non-negotiable performance
rules live in [CLAUDE.md](./CLAUDE.md). Read that before changing anything.

## Stack

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS v4**
- **GSAP** + ScrollTrigger for every scroll animation
- **Lenis** for smooth scroll (native touch — `syncTouch: false`)
- Deploy target: Vercel

## Commands

```bash
npm run dev     # local dev
npm run build   # production build — must pass before anything is "done"
npm run lint    # after edits
```

## Layout

```
src/
  app/                 layout, page, globals.css
  components/
    sections/          Loading, Hero, About, Ambience, Reservation, Footer
    SmoothScroll.tsx   Lenis <-> ScrollTrigger wiring
    BelowFold.tsx      code-splitting boundary below the hero
  hooks/               useMediaQuery, usePreloader, useReducedMotion
  lib/
    assets.ts          single source of truth for every asset path
    gsap.ts            registers ScrollTrigger once, client-only
    reservation.ts     time slots + WhatsApp deep link
public/assets/         hero, ambience, brand, reservation
```

## Notes for whoever picks this up

- Reference recordings used to build the hero and ambience animations live outside
  the repo in `../_zoi-references/` — they are 21 MB of screen capture and do not
  belong in git.
- The hero and ambience sections share one video encode. There is no distinct
  ambience footage yet; `HERO_VIDEO` is deliberately reused so the HTTP cache
  serves it once.
- The reservation form has **no backend**. It builds a `wa.me` deep link and the
  visitor sends the message themselves.
- `AGENTS.md` is generated by `next dev` — it reappears if you delete it.
